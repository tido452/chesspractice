# Chess Lab — Godot 4.x 화면 배치 수정본

## 수정 이유

이전 버전은 `main.gd`의 `_label()`에서 **모든** Label을 자동 줄바꿈하도록 설정했습니다. Godot `HBoxContainer` 안에 있는 타이틀과 상태 표시 Label까지 최소 너비가 작아져 글자가 세로로 줄바꿈되고, 그 라벨의 비정상적인 높이 때문에 상단 패널이 화면을 밀어내 체스판이 보이지 않았습니다.

이번 버전에서는 `Label` 기본값을 `AUTOWRAP_OFF`로 바꾸고, 긴 코칭 설명·힌트·알림·지시문에만 줄바꿈을 적용했습니다. 또한 부모가 추가된 다음 루트 컨테이너의 Full Rect 앵커를 설정하고, 좌/중/우 열과 체스판에 명시적인 최소 크기를 부여했습니다.

## 실행

1. 이 ZIP을 **새 폴더**에 압축 해제하세요. 같은 폴더에 구버전을 덮어쓰지 않는 편이 안전합니다.
2. Godot 4.5.1 프로젝트 관리자에서 `project.godot`를 가져오세요.
3. F5로 프로젝트 실행. 최초 실행 시 1440×900 기준 화면이 나타납니다.
4. `역사적 명국`, `전술 퍼즐`, `직관 훈련`, `자유 분석` 메뉴를 이용할 수 있습니다.

기존 기보와 퍼즐 데이터, 체스 규칙은 유지했습니다. Stockfish 실시간 엔진은 포함되지 않습니다.

**검증 범위:** 실제 사용자가 보고한 화면 캡처와 GDScript 소스의 상호작용을 근거로 레이아웃 원인을 수정했습니다. 이 제작 환경에는 Godot 실행 파일이 없으므로 실제 에디터에서 구동 테스트를 마쳤다고 주장하지 않습니다.
